# AFTERGLOW // ARTILLERY

Яркая браузерная пошаговая артиллерия по мотивам классической формулы
Scorched Earth: два танка меняют рельеф выстрелами, считают ветер и между
раундами тратят заработанные кредиты на новое оружие.

Главная особенность вертикального среза — узнаваемая хореография оружия.
Механический результат рассчитывается отдельно от частиц, звука, свечения и
тряски камеры, поэтому зрелище не подменяет тактику.

## Что уже есть

- локальный hot-seat матч для двух игроков на три раунда;
- процедурный разрушаемый рельеф, баллистика и ветер;
- шесть видов оружия с разными траекториями и яркими эффектами;
- здоровье, щиты, награды и магазин между раундами;
- управление с touch-экрана, мыши и клавиатуры;
- полноэкранный landscape-first интерфейс с safe areas;
- reduced-motion режим и синтезированный Web Audio без внешних ассетов;
- детерминированное TypeScript-ядро с unit-тестами.

Игра не копирует исходный код, графику, звук или тексты оригинала. Публичная
оболочка и все визуальные материалы созданы для этого проекта.

## Локальный запуск

Нужны Node.js 22.19+ и npm.

```bash
npm ci
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000). На
телефоне используйте альбомную ориентацию.

## Управление

- `↑` / `↓` — угол;
- `←` / `→` — сила;
- `Q` / `E` — выбрать оружие;
- `Space` — выстрел;
- экранные слайдеры и кнопки дублируют все действия на touch-устройствах.

## Проверка

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run test:render
```

Полная локальная проверка выполняется одной командой:

```bash
npm run check
```

## Структура

- `app/game/` — React-интерфейс, Canvas presentation, VFX и звук;
- `lib/game/` — чистая симуляция, рельеф, физика и каталог оружия;
- `tests/` — unit- и server-render проверки;
- `docs/` — продуктовый замысел, архитектура, спецификации и решения;
- `.openai/` и `worker/` — конфигурация сборки и публикации в ChatGPT Sites.
