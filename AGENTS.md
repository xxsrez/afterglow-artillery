# AGENTS.md

Инструкции действуют для всего репозитория.

## Текущее состояние

- В репозитории есть играбельный vertical slice локального hot-seat матча.
- Приложение собирается через vinext/Vite для ChatGPT Sites; основной язык —
  TypeScript в строгом режиме.
- Чистое доменное ядро находится в `lib/game/`, React/Canvas presentation — в
  `app/game/`.
- Проверенные точки входа: `npm run dev`, `npm run check` и
  `npm run test:render`. Не заявляйте новый результат проверки, не запустив
  соответствующую команду на текущем commit.

## Неизменные продуктовые принципы

- Основа игры — пошаговая 2D-артиллерия: угол, сила, ветер, баллистика,
  разрушаемый рельеф, повреждения, выживание и покупки между раундами.
- В каноническом режиме сохраняйте функциональные роли, взаимные контрмеры и
  наблюдаемый баланс Scorched Earth 1.5. Не меняйте цены, урон, радиусы,
  экономику или порядок разрешения эффектов без измерений и явного решения.
- Базовый снаряд всегда доступен: игрок не должен остаться без возможности
  сделать осмысленный ход.
- Яркая анимация — часть идентичности оружия, но не источник истины. Исход
  выстрела рассчитывает симуляция; визуальный слой только объясняет результат.
- Эффект обязан оставлять читаемыми траекторию, место попадания, область
  воздействия, урон и изменение рельефа.
- Mobile-first не означает упрощённую механику. Крупные touch-элементы,
  точная пошаговая коррекция угла/силы и безопасная кнопка огня должны
  сосуществовать с клавиатурой и мышью.

## Технические границы реализации

- Основной язык — TypeScript со строгой проверкой типов.
- Симуляция, данные оружия и экономика должны быть отделены от движка,
  DOM-интерфейса, аудио и графических эффектов.
- Детерминированные системы используют фиксированный шаг и явно переданный
  seed. Не обращайтесь к глобальной случайности или времени из доменной логики.
- Визуальные частицы, тряска камеры, звук и post-processing не могут менять
  коллизии, урон или состояние рельефа.
- Рельеф должен поддерживать пещеры, туннели и нависающие участки; обычной
  одномерной карты высот для этого недостаточно.
- Текущий вертикальный срез использует Canvas 2D и React controls. Не добавляйте
  игровой framework либо второй renderer без измеримого ограничения текущего
  решения и нового ADR.
- Не добавляйте backend, аккаунты, сетевой multiplayer или обязательную PWA
  инфраструктуру до отдельного решения.

## Качество

- Механику проверяйте unit- и property-тестами на чистой симуляции.
- Для баллистики и рельефа используйте воспроизводимые сценарии с seed и
  эталонными состояниями до/после.
- Критические пользовательские потоки проверяйте в реальном браузере и на
  touch-устройстве, а не только в эмуляции desktop viewport.
- Для тяжёлых эффектов измеряйте frame time, число частиц, draw calls, память
  текстур и длительность разрешения выстрела на обозначенном устройстве.
- Не заявляйте о совместимости, производительности или балансовом паритете без
  зафиксированного сценария и результата.

## Документация

- Основной язык проектной документации — русский; технические термины можно
  оставлять на английском, когда это точнее.
- Следуйте ленивой структуре `project-docs`: создавайте файл или каталог только
  для реального содержания, связывайте его с `docs/README.md`, не делайте
  заглушек «на будущее».
- Явно различайте принятое решение, предложение, проверенный факт и открытый
  вопрос.
- При изменении правил обновляйте спецификацию, соответствующий ADR и
  справочник только там, где меняется их собственная зона ответственности.

## Интеллектуальная собственность

- Не копируйте из оригинала исполняемые файлы, исходный код, графику, звук,
  тексты, интерфейс или файлы конфигурации в продукт.
- Факты из официального руководства допустимы как исследовательская база с
  указанием источника; публичный контент должен получить собственные названия,
  оформление и формулировки.
- `Scorched Earth` считается рабочим названием. Не представляйте его
  доступность для релиза как установленный юридический факт.
