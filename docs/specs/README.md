# Спецификации

Здесь описывается поведение продукта. Подмножество vertical slice реализовано,
но более широкий MVP, balance parity и playtest-критерии остаются
предложениями. Принятые исходные ограничения зафиксированы отдельно в
[ADR-0001](../decisions/0001-product-and-platform-foundation.md).

Точная граница работающей версии перечислена в
[описании реализации](../implementation.md).

- [Игровой цикл и объём](game-design.md) — правила матча, экономика, UX,
  этапы и критерии успеха.
- [Эффекты оружия](weapon-effects.md) — визуальная грамматика, читаемость,
  доступность и производственные ограничения.

При расхождении механический результат определяется спецификацией игры, а
спецификация эффектов определяет, как этот результат показывается.
