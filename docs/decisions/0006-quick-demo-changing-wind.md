# ADR-0006: Меняющийся ветер Quick Demo

- **Статус:** принято
- **Дата:** 2026-07-29

## Контекст

Официальный manual Scorched Earth 1.5 подтверждает опцию `Changing Wind`: при
её включении ветер слегка меняется между каждым выстрелом. Default оригинала —
`Off`, `Max Wind = 200`, доступный диапазон `0–500`. Формула, распределение и
состояние генератора не опубликованы, а официальный FAQ подтверждает, что
исходный код недоступен.

Quick Demo 0.1 должен показывать меняющуюся погоду по умолчанию. Независимый
reroll полного диапазона только в начале раунда не давал инерции, штиля и
естественного перехода направления.

## Решение

Принять pure seeded state в `lib/game/wind.ts`:

```ts
interface WindState {
  value: number;    // normalized [-1, 1]
  velocity: number; // trend
}
```

После полного разрешения каждого shot, включая последний shot раунда, и до
следующего `aiming` выполняется ровно один переход:

```text
gust = 0.27 × (u1 - u2)
velocity' = clamp(0.65 × velocity - 0.18 × value + gust, -0.31, 0.31)
value' = reflect(value + velocity', -1, +1)
```

При отражении `velocity'` меняет знак и умножается на `0.55`. `u1` и `u2`
берутся из отдельного stream, адресуемого seed матча и номером завершённого
shot. Presentation не потребляет этот stream.

Quick Demo задаёт ruleset-данными `maxWind = 90` и
`changingWind = true`. Normalized value квантуется в integer ruleset units
один раз на границе хода; это одно значение получают HUD и trajectory
simulation. Изменение ограничено `floor(0.31 × maxWind)` и составляет минимум
одну видимую единицу. При `maxWind = 0` или `changingWind = false` значение
остаётся фиксированным. Состояние и trend переходят между раундами; новый матч
создаёт новый seeded state.

Эта формула — **НЕ каноническая формула Scorched Earth**. Это собственный
provisional calibration profile Quick Demo 0.1. Коэффициенты нельзя менять без
повторной статистической проверки и обновления этого ADR.

## Калибровка

Детерминированный тест использует seeds `0…9999`, по `40` состояний на seed и
calm zone `|wind| ≤ 9` при `maxWind = 90`.

| Метрика | Результат | Критерий |
|---|---:|---:|
| Среднее | `-0.150` units (`-0.17% maxWind`) | не дальше `±3% maxWind` |
| Lag-1 autocorrelation | `0.897` | `0.75–0.95` |
| Медианная длина пребывания по одну сторону calm zone | `4` shots | `4–8` |
| 16-shot sequences с обоими направлениями | `95.93%` | не меньше `90%` |
| Состояния ровно на `±maxWind` | `0.03%` | меньше `1%` |

На том же наборе каждый включённый переход сохраняет
`|wind| ≤ maxWind`, меняет integer wind и не превышает `27` units.

## Последствия

- Перезапуск с тем же seed воспроизводит всю wind sequence.
- Wind фиксирован во время flight и resolution; VFX и frame rate его не
  меняют.
- Quick Demo и Infinite Arsenal используют одинаковую модель: ammo policy не
  входит в wind input.
- Classic обязан оставлять `Changing Wind = Off` представимым ruleset-данными.
- Любая заявка на parity с оригиналом всё ещё требует black-box исследования.
